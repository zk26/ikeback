# Security Policy

## Supported Versions

Only the latest stable ikeback release series receives security fixes. Older releases are not supported.

| Version | Supported          |
| ------- | ------------------ |
| 5.3.x   | ✔️                 |
| < 5.3.x | ❌                 |

## Reporting a Vulnerability

If you have found a security-related bug in Ikeback, please contact us via email at security@ikeback.io to disclose the details about your findings. As soon as we learn about potential security vulnerabilities, we will work together to analyze and fix them as soon as possible.
